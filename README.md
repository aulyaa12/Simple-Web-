# PANGANITA — Sahabat Gizi dan Panen Ibu Nusantara

Ini adalah web sederhana yang dibuat sebagai latihan pembangunan aplikasi web menggunakan **Next.js** dan **Tailwind CSS**. Project ini dikerjakan untuk memenuhi tugas Front-End Development pada program **Markoding — Perempuan Inovasi**, sekaligus menjadi dasar pengembangan project akhir bertema **Ketahanan Pangan, Gizi Perempuan & Keluarga**.

## Tentang Project

PANGANITA adalah konsep aplikasi yang membantu ibu mengelola hasil panen dan kebutuhan gizi keluarga, dengan asisten AI bernama **Bu Nita**. Versi ini masih berupa landing page dan latihan fitur dasar front-end, belum termasuk fitur AI yang sesungguhnya.

## Fitur yang Dipelajari dan Diterapkan

- Tampilan landing page (Beranda, Tentang, Layanan, Profil, Bantuan)
- Navigasi antarhalaman menggunakan Next.js App Router
- Daftar **UserCard** yang diambil dari API [JSONPlaceholder](https://jsonplaceholder.typicode.com/users)
- Fitur **Favorite Users** — menambah dan menghapus user favorit menggunakan React Context
- Halaman **Favorites** yang menampilkan daftar user yang telah ditandai favorit

## Teknologi yang Digunakan

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- React Context API

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.
